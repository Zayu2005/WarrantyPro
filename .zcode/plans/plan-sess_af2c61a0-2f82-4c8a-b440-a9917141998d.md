## 系统总体设计（文档中展开论证）

**产品形态——「三端一云 + AI Agent」，五个角色**
- **鸿蒙端 App**（HarmonyOS NEXT，ArkTS/ArkUI），按角色区分界面：
  - 业主/住户：「小保」对话式报修助手、传统表单报修、实时进度、验收评价、服务卡片
  - 维修师傅：待办工单/接单提醒（Push）、接受或申请改派、进度更新、维修前后照片、维修记录（Agent 辅助生成）、维修方案推荐
- **PC 端 Web 管理后台**（Vue3 + Element Plus + ECharts）：
  - 物业客服/调度员：工单受理、查看 Agent 派单推荐与理由、一键确认/人工干预派单、催办
  - 物业管理层：保修台账、统计大屏、自然语言查数与周报（运营分析 Agent）
  - 系统管理员：用户/角色/权限、小区房产数据、知识库维护
- **后端统一服务**（Spring Boot 3 模块化单体 + AI Agent 服务层）：RESTful API + MySQL + Redis + MinIO + WebSocket + SSE

**核心业务闭环**
业主对话式/表单报修 → 自助排障建议（Agent 前置拦截无效工单）→ 保修判定引擎判定保修期内/外 → 期外工单由智能派单 Agent 决策（技能×负载×位置×评分 + 可解释理由），客服确认或自动派单 → 师傅接单（Push，超时自动改派）→ 维修（Agent 辅助方案推荐）→ 完工提交 → 业主验收评价 → 数据沉淀为保修台账与绩效统计。保修期内工单自动路由开发商/承建商对接人。

**AI Agent 体系（4 核心 + 1 可选，技术底座：Spring AI + 国产大模型 API 可配置 + RAG + SSE + Function Calling）**
1. 「小保」对话式报修助手（鸿蒙端·业主）——多轮引导 + 照片识别故障类型 + 结构化工单预填 + 自助排障建议
2. 智能派单 Agent（后端+PC 端）——Agent 决策 + 可解释推荐理由 + 自动派单/超时改派 + 人工可干预
3. 维修辅助 Agent（鸿蒙端·师傅）——相似工单检索 + 方案与材料推荐 + 维修记录辅助生成
4. 运营分析 Agent（PC 端·管理层，可选）——自然语言查数、周报摘要、异常预警
- 降级策略：大模型不可用时自动退回传统表单报修与规则派单（可靠性设计亮点）

**创新点（比赛评审视角）**
1. 对话式 AI 报修助手 + 多模态故障识别（降门槛、提效率）
2. 智能派单 Agent 与可解释决策
3. 保修期智能判定与责任路由引擎（《建设工程质量管理条例》法定期限 + 合同条款，解决责任推诿）
4. 报修进度全透明 + 鸿蒙服务卡片实时展示
5. 保修资产台账可视化大屏与到期预警
6. 鸿蒙「一次开发多端部署」+ Push Kit 实时触达
